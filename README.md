# 🚛 Генератор коммерческих предложений

Автоматический генератор КП для автоперевозок с поддержкой ИИ (Ollama) и креативных шаблонов.

## ✨ Возможности

- 📍 **3 региона:** Юга, Владивосток, Восток
- 🤖 **Два режима работы:**
  - Классический генератор на шаблонах
  - Версия с генерацией через локальный ИИ (Ollama)
- 📋 Копирование в буфер обмена
- 📄 Экспорт в Word (1 или 3 варианта)
- 💾 Автосохранение выбора городов и региона
- 🎨 Креативный режим «Без города» для Востока
- 📊 Логирование всех действий

## 🚀 Быстрый старт

### 1. Установка Python
Скачайте Python 3.10+ с [python.org](https://www.python.org/downloads/)

### 2. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 3. Запуск

**Без ИИ (шаблоны):**
```bash
python src/генератор_кп.py
```

**С ИИ (требуется Ollama):**
```bash
# 1. Установите Ollama: https://ollama.com/
# 2. Загрузите модель:
ollama pull qwen2.5:7b
# 3. Запустите:
python src/генератор_кп_ollama.py
```

### 4. Меню запуска (Windows)
Дважды кликните `scripts/Генератор КП.bat` — откроется меню с установкой, запуском и очисткой логов.

## ⚙️ Настройки

Программа сама создаёт `settings.json` в корне проекта при первом закрытии окна
(выбранные города и регион сохраняются автоматически). Этот файл **не попадает
в Git** — он пользовательский.

Чтобы начать с готового набора городов, скопируйте пример:

```bash
copy config\settings.example.json settings.json
```

Поддерживаемые поля:

| Поле | Описание | По умолчанию |
|---|---|---|
| `cities` | Список выбранных городов | пусто |
| `region` | `Юга`, `Владивосток` или `Восток` | `Юга` |
| `use_ai` | Использовать ИИ (только версия с Ollama) | `true` |
| `model` | Имя модели Ollama | первая доступная |
| `creativity` | Температура генерации | `0.8` |

Логи пишутся в `logs/generator_ГГГГММДД.log` (ротация: 10 МБ, 5 копий).

## 🤖 Ollama (опционально)

```bash
# Проверка что запущен
curl http://localhost:11434/api/tags

# Рекомендуемые модели
ollama pull qwen2.5:7b      # быстрая, хорошая для русского
ollama pull llama3.1:8b     # альтернатива
```

## 📦 Сборка EXE

```bash

python scripts/setup.py
```

Готовый `.exe` появится на рабочем столе.
