# 🚛 Генератор коммерческих предложений

Автоматический генератор КП для автоперевозок с поддержкой ИИ (GigaChat, Ollama) и креативных шаблонов.

## ✨ Возможности

- 📍 **3 региона:** Юга, Владивосток, Восток
- 🤖 **Три режима работы:**
  - Классический генератор на шаблонах
  - Версия с облачным ИИ (**GigaChat** — быстро, нужен API-ключ)
  - Версия с локальным ИИ (**Ollama** — без ключа, работает офлайн)
- 📋 Копирование в буфер обмена
- 📄 Экспорт в Word (1 или 3 варианта)
- 💾 Автосохранение выбора городов и региона
- 🎨 Креативный режим «Без города» для Востока
- ⚡ Асинхронная генерация — интерфейс не «зависает»
- 📊 Логирование всех действий (без секретов)

## 🚀 Быстрый старт

### 1. Установка Python
Скачайте Python 3.10+ с [python.org](https://www.python.org/downloads/)

### 2. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 3. Запуск

**Без ИИ (шаблоны):**
```bash
python src/генератор_кп.py
```

**С GigaChat (облачный ИИ, нужен ключ):**
```bash
# ключ задаётся в .env (см. раздел «GigaChat» ниже)
python src/генератор_кп_gigachat.py
```

**С Ollama (локальный ИИ, ключ не нужен):**
```bash
# 1. Установите Ollama: https://ollama.com/
# 2. Загрузите модель:
ollama pull qwen2.5:7b
# 3. Запустите:
python src/генератор_кп_ollama.py
```

### 4. Меню запуска (Windows)
Дважды кликните `scripts/Генератор КП.bat` — откроется меню:

| Пункт | Действие |
|---|---|
| **[1]** | Запустить генератор (Ollama — локальный ИИ) |
| **[2]** | Запустить генератор (GigaChat — облачный ИИ) |
| **[3]** | Установить библиотеки |
| **[4]** | Ввести API-ключ GigaChat |
| **[5]** | Создать ярлык на рабочем столе |
| **[6]** | Очистить логи |
| **[7]** | Выход |

## ⚙️ Настройки

Программа сама создаёт `settings.json` в корне проекта при первом закрытии окна
(выбранные города и регион сохраняются автоматически). Этот файл **не попадает
в Git** — он пользовательский.

Чтобы начать с готового набора городов, скопируйте пример:

```bash
copy config\settings.example.json settings.json
```

Поддерживаемые поля:

| Поле | Описание | По умолчанию |
|---|---|---|
| `cities` | Список выбранных городов | пусто |
| `region` | `Юга`, `Владивосток` или `Восток` | `Юга` |
| `use_ai` | Использовать ИИ (версии с GigaChat и Ollama) | `true` |
| `creativity` | Температура генерации | `0.8` |

Логи пишутся в `logs/generator_ГГГГММДД.log` (ротация: 10 МБ, 5 копий).

## 🤖 GigaChat (опционально, облачный ИИ)

Более быстрый и качественный, чем Ollama, но требует API-ключ.

### Получение ключа
1. Регистрация: https://developers.sber.ru/
2. Личный кабинет → Настройки → Authorization Key (base64)

### Настройка
1. Запустите `scripts/Генератор КП.bat`
2. Выберите пункт **[4] Ввести API-ключ GigaChat**
3. Вставьте ключ (он сохранится в `.env`)

### Запуск
Пункт **[2] Запустить генератор (GigaChat)** в том же меню.

### ⚠️ Безопасность
- Ключ хранится только в `.env` (в `.gitignore`)
- Никогда не коммитьте `.env` в Git
- При утечке ключа — отзовите его в личном кабинете GigaChat
- Ключ маскируется в логах как `***` и не попадает ни в логи, ни в `settings.json`

### ⚙️ Переменные `.env`

| Переменная | Описание | По умолчанию |
|---|---|---|
| `GIGACHAT_CREDENTIALS` | Authorization Key (base64) | — |
| `GIGACHAT_SCOPE` | `GIGACHAT_API_PERS` / `_B2B` / `_CORP` | `GIGACHAT_API_PERS` |
| `GIGACHAT_MODEL` | Модель | `GigaChat` |
| `GIGACHAT_TIMEOUT` | Таймаут запроса, сек | `30` |
| `GIGACHAT_VERIFY_SSL_CERTS` | Проверка SSL-сертификата | `true` |
| `GIGACHAT_CA_BUNDLE_FILE` | Путь к корневому сертификату Минцифры | — |

Начать можно с шаблона: скопируйте `.env.example` в `.env` и заполните значения.

### 🔧 Если ошибка SSL (`certificate verify failed`)

За корпоративным прокси или антивирусом (Kaspersky, Dr.Web и подобные) GigaChat
может не пройти проверку сертификата. Решение — указать корневой сертификат
Минцифры:

1. Скачайте https://gu-st.ru/content/Other/doc/russian_trusted_root_ca.cer
2. Пропишите путь в `.env`:
   ```
   GIGACHAT_CA_BUNDLE_FILE=C:\certs\russian_trusted_root_ca.cer
   ```

Отключать `GIGACHAT_VERIFY_SSL_CERTS` (ставить `false`) не рекомендуется — это
делает соединение уязвимым. Используйте только для локальной отладки.

### ⚡ Скорость

Генерация оптимизирована: короткий промпт, `max_tokens=280`, потоковый ответ
и переиспользование авторизации. Клиент GigaChat прогревается в фоне при старте,
а интерфейс не блокируется во время запроса. Если GigaChat недоступен
(нет сети, неверный ключ, ошибка SSL) — текст автоматически соберётся из шаблонов.

## 📁 Структура проекта

```
├── src/                        # Исходный код
│   ├── генератор_кп.py         # Шаблонная версия
│   ├── генератор_кп_ollama.py  # Версия с локальным ИИ (Ollama)
│   ├── генератор_кп_gigachat.py# Версия с облачным ИИ (GigaChat)
│   ├── llm_provider.py         # Единый провайдер LLM (GigaChat + Ollama)
│   └── logger_config.py        # Пути проекта и логирование
├── scripts/                    # Скрипты сборки и запуска
│   └── Генератор КП.bat        # Главное меню (запуск, ключ, логи)
├── config/                     # Пример конфигурации
├── .env.example                # Шаблон настроек GigaChat (коммитится)
├── .env                        # Ваш ключ GigaChat (НЕ коммитится)
├── requirements.txt
├── .gitignore
└── README.md
```
